# Security NFR — Study Planner

| ID | Название | Описание | Метрика/Порог | Проверка (чем/где) | Компонент | Приоритет |
|----|-----------|-----------|----------------|---------------------|-----------|-----------|
| NFR-01 | Безопасность данных пользователей | Личные данные (темы, дедлайны, прогресс) хранятся в шифрованном виде | AES-256 at rest | Просмотр конфигурации БД/ORM, проверка ключей KMS | Backend (DB) | High |
| NFR-02 | Защита паролей | Хранение паролей только в виде хэшей с солью | Argon2id t=3, m=64MB, p=2 | Код-ревью, unit-тесты на параметры KDF | Auth Service | High |
| NFR-03 | Время отклика API | Быстрый отклик под типичной нагрузкой | p95 ≤ 300 мс | APM (Prometheus/Grafana), нагрузочное тестирование | Backend API | Medium |
| NFR-04 | Доступность сервиса | Высокая доступность для пользователей | Uptime (календарный месяц) ≥ 99.5% | StatusPage/Heartbeat мониторинг | Infrastructure | High |
| NFR-05 | Ограничение запросов | Защита от бурстов и абьюза | Rate limit ≤ 100 RPS на токен/IP | API Gateway rate limiter + логи | API Gateway | Medium |
| NFR-06 | Жизненный цикл JWT | Ограниченный TTL и обновление по refresh | Access JWT TTL = 3600 сек, refresh = 30 дней | Интеграционные тесты, проверка middleware | Auth Service | Medium |
| NFR-07 | Ротация секретов | Регулярная ротация секретов/ключей | Период ≤ 30 дней | CI/CD check, записи в секрет-менеджере | DevOps | Low |
| NFR-08 | Контроль ошибок | Доля 5xx под контролем | error rate (5xx) ≤ 0.1% | Логи/метрики, алёрты в PagerDuty | Backend API | High |
