# ADR-003 — Client HTTP Policies (таймауты, ретраи, лимиты)

## Context
Внешние HTTP-зависимости могут вызывать задержки или ошибки, нужно ограничивать их негативное влияние на сервис.

## Decision
- Для всех исходящих HTTP-запросов выставляется таймаут (3с по умолчанию),
- Вводятся ретраи (до 3 попыток),
- Ограничивается одновременное число соединений (через connection pool по умолчанию).

## Alternatives
1. Без таймаутов (но тогда приложение может "зависнуть" при недоступности внешнего сервиса).
2. Без retry (но тогда временные ошибки сразу отлетают клиенту, снижается устойчивость).

## Security impact
Решение уменьшает влияние отказов внешних сервисов, позволяет избежать цепных DoS и не блокировать основной API.

## Rollout plan
- Новый эндпоинт /external_proxy доступен, отдаёт ошибку при провале запроса.
- Тестируется негативный и позитивный сценарий по ошибкам HTTP-клиента.
