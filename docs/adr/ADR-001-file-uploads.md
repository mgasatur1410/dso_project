# ADR-001 — Secure File Uploads

## Context
Пользователи должны иметь возможность безопасно загружать файлы. Необходимо снизить риск вредоносных загрузок и атак через подмену расширений или имён файлов.

## Decision
Реализован endpoint загрузки файлов с:
- Валидацией magic bytes и MIME-типа
- Лимитом размера
- Сохранением с UUID-именем файла
- Запретом любых попыток Path Traversal

## Alternatives
1. Просто проверять MIME-type (без magic bytes): проще, но легко обойти, подменив тип на клиенте.
2. Сохранять оригинальное имя файла: проще в использовании, но опасно (XSS/Path Traversal/конфликт имён).

## Security impact
Это решение снижает риски Path Traversal и загрузки вредоносов, гарантирует уникальность и непредсказуемость имён файлов, добавляет технические барьеры для попыток эксплуатации сервиса через загрузки.

## Rollout plan
- Эндпоинт доступен для загрузки
- Валидация и ограничения работают (покрыто тестами)
- Ошибки возвращают корректные статусы
