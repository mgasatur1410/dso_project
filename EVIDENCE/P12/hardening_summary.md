# P12 hardening summary

## Dockerfile
- Многостадийная сборка (`build` / `test` / `runtime`) на `python:3.11-slim` без `latest`.
- Процесс запускается от non-root пользователя `app` (UID 1000), ограничены права на `/app`.
- Конфигурация и секреты предполагается передавать через переменные окружения / внешние тома, а не хардкодить в образ.

## IaC (docker-compose)
- Сервис `app` описан в `iac/docker-compose.yaml` и использует локальный образ `secdev-app:local`.
- Порт 8000 проброшен наружу только для приложения; остальная инфраструктура не открывается на `0.0.0.0/0` сверх необходимого.

## Статические проверки
- Hadolint: запускается с конфигом `security/hadolint.yaml`, отключены нерелевантные правила (DL3008, DL3013).
- Checkov: использует `security/checkov.yaml` для базового тюнинга проверок K8s/compose.
- Trivy: сканирует образ `secdev-app:local` с фокусом на CRITICAL/HIGH/MEDIUM; результаты попадают в `EVIDENCE/P12/trivy_report.json` и будут использоваться для планирования обновлений base-образа/зависимостей.
